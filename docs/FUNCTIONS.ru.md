# Функции и переменные шаблонизатора Omnifetch

Шаблоны вывода живут в `~/.config/omnifetch/config.toml`, в секции `[format]`. Любой текст вне `{скобок}` печатается дословно:

```toml
[format]
memory = "{f} свободно из 1337GB"
# -> 4.24 GiB свободно из 1337GB
```

Модуль с единственным значением, например `os` или `host`, печатает это значение как есть и секцию `[format]` игнорирует.

## 2. Функции

Функцию можно записать тремя способами, и все три ведут в один и тот же код с одним и тем же значением:

- **вызов**: `{upper(name)}`, `{trunc(name, 20)}`, `{bar(15, '=', '-')}`
- **фильтр**: `{name \| upper}`, `{name \| remove('(R)') \| trunc(20)}`
- **двоеточие**: `{used:gib}`, `{pct:round(1)}`, `{bar:15:=:-}`

Цепочки тоже работают: `{name:remove('Intel(R) '):upper}`

Конвертеры единиц всегда получают исходное число, а не отформатированный текст, поэтому `{used:gib}` и `{gib(used)}` сходятся, хотя plain `{used}` печатает `"3.37 GiB"`.

### Строки

| Функция | Псевдоним | Описание |
| :--- | :--- | :--- |
| `upper(s)` / `s:upper` | `uppercase` | ВЕРХНИЙ РЕГИСТР |
| `lower(s)` / `s:lower` | `lowercase` | нижний регистр |
| `title(s)` / `s:title` | `capitalize` | Заглавные Буквы Каждого Слова |
| `trunc(s, len)` / `s:trunc(len)` | `truncate` | Не больше `len` символов, включая многоточие (не режет UTF-8) |
| `replace(s, old, new)` | | Каждое вхождение `old` заменяется на `new` |
| `remove(s, pattern)` | | Каждое вхождение `pattern` удаляется |
| `trim(s)` | | Убирает пробелы с обоих концов |
| `pad_left(s, width)` | | Дополняет слева, текст прижат вправо |
| `pad_right(s, width)` | | Дополняет справа, текст прижат влево |

### Единицы и числа

| Функция | Псевдоним | Пример вывода |
| :--- | :--- | :--- |
| `gib(bytes)` / `s:gib` | `gb` | `7.62 GiB` |
| `mib(bytes)` / `s:mib` | `mb` | `7802.5 MiB` |
| `kib(bytes)` / `s:kib` | `kb` | `7990000 KiB` |
| `raw(bytes)` / `s:raw` | `bytes`, `b` | Голое целое число, без единиц |
| `human(bytes)` / `s:human` | | Автоматический масштаб: `B`, `KiB`, `MiB`, `GiB`, `TiB` |
| `round(number, decimals)` | | Округление до заданного числа знаков |

### Прогресс-бары

| Функция | Описание |
| :--- | :--- |
| `bar(width)` | Полоска, ширина и символы по умолчанию |
| `bar(width, fill, empty)` | Свои символы для заполнения и пустоты, в кавычках |
| `bar_color(width)` | Полоска с цветом по проценту: зеленый (<60%), желтый (60-85%), красный (>85%) |

### Запасные значения

| Функция | Описание | Пример |
| :--- | :--- | :--- |
| `default(val, fallback)` | Запасное значение, если `val` пуст | `{freq:default('N/A')}` |

### Системные и время

| Функция | Описание |
| :--- | :--- |
| `env(NAME)` | Читает переменную окружения |
| `date(format)` | `strftime`, текущие дата и время |
| `time(format)` | То же, что `date` |

### Цвета и атрибуты

- **Базовые цвета**: `{red}`, `{green}`, `{yellow}`, `{blue}`, `{magenta}`, `{cyan}`, `{white}`, `{black}`
- **Яркие цвета**: `{bright_red}`, `{bright_green}`, `{bright_yellow}`, `{bright_blue}`, `{bright_magenta}`, `{bright_cyan}`, `{bright_white}`
- **Серые цвета**: `{gray}` и `{grey}` (оба означают `{bright_black}`)
- **Стили**: `{bold}`, `{reset}`

## 3. Арифметика

### Байтовая арифметика (memory, swap, disk)

```text
{used + 2 GiB}     # Добавляет 2 GiB, результат в человеческих единицах
{used - 500 MiB}
{used * 2}
{used / 2}
{used + 2%}        # 2% от total, а не от used
```

### Проценты и числа

```text
{pct + 5%}         # 45% превращается в 50%
{pct - 2%}
{pct * 1.5}
```

Изменение `{used}` сдвигает `{bar}` и `{pct}` вместе с собой, так как они считывают скорректированную метрику.

### Допустимые единицы в арифметике

- Байты: `b`, `byte`, `bytes`
- Килобайты: `k`, `kb`, `kib`
- Мегабайты: `m`, `mb`, `mib`
- Гигабайты: `g`, `gb`, `gib`
- Терабайты: `t`, `tb`, `tib`
- Проценты: `%`, `percent`

### Случайные диапазоны

```text
{used + 2..4 GiB}  # Случайное число между 2 и 4 GiB, разное при каждом запуске
{pct + 2..5%}
{2..4 GiB}         # Отдельное случайное значение
```

## 4. Пример конфигурации

```toml
# ~/.config/omnifetch/config.toml

[bar]
width = 16
fill = "■"
empty = " "

[keys]
memory = "RAM"
swap = "SWAP"
disk = "Storage"
cpu = "Processor"

[format]
memory = "{used + 2..4 GiB} / {total} {bar} {pct}%"
swap = "{used * 2} / {total} {bar} {pct}%"
disk = "{mount} {used} / {total} {bar} ({pct}%)"
cpu = "{name | remove('Intel(R) ') | remove('Core(TM) ') | upper} ({cores}) @ {freq}"
battery = "{bar(10)} {pct}%{status}"
title = "{bold}{cyan}{user}{reset}@{bold}{host}{reset}"
```
